## Selected public work

A cinematic coffee-industry concept experience, with scroll-driven 3D storytelling, interactive scenes, accessibility fallbacks, and automated browser QA. **Fictional brand / demonstration project.**

**Stack:** Next.js, React, TypeScript, Tailwind CSS, Three.js, React Three Fiber, Drei, GSAP, Playwright.

**Technology:** HTML, Three.js, WebGL / 3D assets.

**Technology:** HTML, CSS, JavaScript, Node.js, Playwright, Sharp.
